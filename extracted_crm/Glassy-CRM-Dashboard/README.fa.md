# داشبورد شیشهٔ مایع CRM — نسخهٔ ۱.۱

این پروژه با بررسی دو ویدئوی `dashboard.mp4` و `sidebar.mp4` و بازنویسی رابط از روی مرجع بصری ساخته شده است. هر پنج صفحهٔ ویدئوی داشبورد پیاده‌سازی شده‌اند. فرم شیشه‌ای سایدبار، برند CODEXR، پروفایل، نشانگر اعلان، دکمهٔ روی لبه و تبدیل حالت باز به حالت جمع‌شده از کلیپ دوم دنبال شده است. نام منوها با بخش‌های همین CRM هماهنگ شده‌اند.

## اجرای سریع

۱. فایل ZIP را استخراج کنید.

۲. فایل **`dist/Glassy-Dashboard.html`** را با دوبار کلیک در مرورگر باز کنید.

این فایل، HTML و CSS و JavaScript و تصاویر SVG را درون خودش دارد. اجرای آن به نصب Node.js، دانلود کتابخانه، CDN، کلید API یا سرویس بیرونی وابسته نیست.

راه دوم، بازکردن `dist/index.html` است. در این حالت فایل‌ها و پوشهٔ `assets` باید در کنار هم باقی بمانند.

## اجرای محلی برای توسعه

با Node.js نسخهٔ ۱۸ یا جدیدتر، در پوشهٔ اصلی اجرا کنید:

```bash
npm start
```

سپس `http://localhost:4173` را باز کنید. اجرای برنامه به `npm install` نیاز ندارد. سرور از ماژول‌های داخلی Node.js استفاده می‌کند. اگر پورت اشغال بود:

```bash
npm start -- --port 4174
```

برای توقف سرور `Ctrl+C` را بزنید.

## تعامل‌ها

- منوها صفحهٔ مربوط را باز می‌کنند؛ وضعیت فعال با مسیرهای `#overview`، `#orders`، `#ecosystem`، `#customers` و `#performance` هماهنگ است.
- سایدبار دسکتاپ در حدود ۳۴۰ میلی‌ثانیه باز و بسته می‌شود. برند در حالت جمع‌شده از CODEXR به CXR تبدیل می‌شود.
- در موبایل، سایدبار کشویی است. دکمهٔ منو، کلیک روی پس‌زمینه و Escape آن را می‌بندند.
- جست‌وجو نام مشتری، سفارش، محصول، سرویس و شاخص‌ها را پیدا می‌کند. میان‌بر `Ctrl+K` یا `⌘+K` فعال است.
- فیلتر سفارش‌ها نتیجه را تغییر می‌دهد و هر ردیف جزئیات خودش را دارد.
- ارسال دستهٔ نمایشی وضعیت سفارش‌های آماده را تغییر می‌دهد؛ سفارش در انتظار تأمین در صف باقی می‌ماند.
- کلید سرویس‌ها، وضعیت کارت، نمودار ترافیک و حلقه‌های مصرف را به‌روز می‌کند.
- انتخاب دورهٔ گزارش، داده‌های نمونهٔ مرتبط را تغییر می‌دهد. صفحهٔ مالی انتخابگر مستقل Q1 تا Q4 دارد.
- CSV سفارش‌ها، CSV مالی، داده‌های JSON و فایل واقعی PDF از داخل رابط دریافت می‌شوند.
- پیش‌نویس پیام ایجاد، ویرایش و حذف می‌شود. هیچ پیامی به شخص یا سرویس بیرونی ارسال نمی‌شود.
- خواندن اعلان‌ها نشانگرهای مربوط را خاموش می‌کند.
- نام پروفایل، تنظیم ظاهر، پاداش نمایشی و تنظیم زبان ذخیره می‌شوند.
- خروج، نشست نمایشی را قفل می‌کند؛ با دکمهٔ بازگشت دوباره وارد می‌شوید.

## ظاهر و فارسی

دو حالت **روشن و تیره** با دکمهٔ خورشید/ماه بالای صفحه تغییر می‌کنند. همین دو گزینه در تنظیمات نیز وجود دارند. در اولین ورود، تم دستگاه انتخاب می‌شود؛ انتخاب دستی شما در مرورگر ذخیره می‌شود و در مراجعهٔ بعدی باقی می‌ماند. داده‌ها و تنظیمات نسخهٔ قبلی حفظ می‌شوند.

سطوح شیشهٔ مایع با شفافیت، محوشدن پس‌زمینه، لبه‌های نورانی، انعکاس نرم و سایه ساخته شده‌اند. دو پس‌زمینهٔ «شیشهٔ مایع» و «جریان شفق» هرکدام نسخهٔ تیره و روشن دارند. حالت روشن از طیف مرواریدی، نقره‌ای و آبی کم‌رنگ استفاده می‌کند و حالت تیره از سرمه‌ای، بنفش و نور فیروزه‌ای. رنگ نوشته‌ها، نمودارها، کنترل‌ها و پنجره‌ها در هر دو تم هماهنگ تغییر می‌کند.

کارت‌ها با محوشدن و جابه‌جایی کوتاه وارد می‌شوند. نمودارهای میله‌ای رشد می‌کنند و نمودارهای خطی از ابتدا رسم می‌شوند. انعکاس نور کارت، نشانگر ماوس را دنبال می‌کند و کارت هنگام اشاره سه پیکسل بالا می‌رود. لکه‌های نور پس‌زمینه حرکت آرام دارند. راهنمای دادهٔ نمودار با ماوس یا فوکوس صفحه‌کلید نمایش داده می‌شود.

چیدمان بر اساس عرض واقعی محتوای داشبورد تغییر می‌کند؛ باز و بسته‌شدن سایدبار هم در آن مؤثر است. در موبایل، نوار ابزار دو ردیفی و سایدبار کشویی است. کارت‌ها، نمودارها و پنجره‌های جزئیات برای عرض‌های کوچک تا ۳۲۰ پیکسل بازچینی می‌شوند. ساختار برای فارسی و انگلیسی و حالت‌های عمودی و افقی در نظر گرفته شده است.

دکمهٔ **FA** بالای صفحه رابط را فارسی می‌کند. جهت صفحه، جای سایدبار و کنترل‌های مربوط مطابق RTL تغییر می‌کنند. اعداد و عبارت‌های لاتین در بخش‌های حساس با `bdi` از متن فارسی جدا شده‌اند. نام محصول و برندهای مرجع حفظ شده‌اند.

کاهش حرکت در تنظیمات وجود دارد. تنظیم کاهش حرکت سیستم‌عامل نیز از طریق `prefers-reduced-motion` رعایت می‌شود و حرکت نور و دنبال‌کردن نشانگر خاموش می‌شوند. در مرورگر بدون پشتیبانی از محوشدن پس‌زمینه، سطح جایگزینِ خوانا نمایش داده می‌شود.

پس‌زمینه‌ها، آیکون‌ها و آواتارها با SVG بازسازی شده‌اند. تصاویر اصلی و کد اصلی طراحی در اختیار نبود. قاب ضبط ویدئو، تیتر تبلیغاتی و پنجرهٔ نمایشی کد پایین کلیپ جزئی از اپلیکیشن نیستند.

## محدودهٔ عملکرد

این تحویل یک **فرانت‌اند تعاملی با داده‌های نمونه** است. API فروشگاه، حسابداری، پرداخت، احراز هویت و پیام‌رسان به آن متصل نشده است. کلید سرویس‌ها اتصال نمایشی را تغییر می‌دهد. نشانگرهای مالی، مالیاتی و انطباق نیز دادهٔ نمونهٔ طراحی هستند.

اطلاعات با `localStorage` و کلید `glassy-crm-v1` در همان مرورگر نگه‌داری می‌شود. داده‌ها بین دستگاه‌ها همگام نمی‌شوند. در صورت محدودشدن ذخیره‌سازی، برنامه همچنان در نشست جاری کار می‌کند.

PDF مالی برای سازگاری فونت بدون کتابخانه به انگلیسی تولید می‌شود. رابط اصلی فارسی/انگلیسی است.

## نقشهٔ کد

| فایل | کاربرد |
| --- | --- |
| `dist/index.html` | پوسته، سایدبار، نوار ابزار و پنجره‌ها |
| `dist/styles.css` | شیشه، سایه، رنگ، چیدمان واکنش‌گرا، RTL و انیمیشن |
| `dist/liquid-glass.css` | رنگ‌ها و سطوح شیشهٔ مایع برای دو تم |
| `dist/liquid-responsive.css` | بازچینی کارت‌ها بر اساس عرض، موبایل، تبلت و حرکت نور |
| `dist/data.js` | داده‌های نمونه و ترجمه‌های فارسی |
| `dist/charts.js` | هشت تابع نمودار SVG مستقل |
| `dist/app.js` | پنج صفحه، مسیریابی، وضعیت، جست‌وجو، فرم‌ها و خروجی‌ها |
| `dist/assets/` | پس‌زمینه‌ها و آواتارهای SVG |
| `dist/Glassy-Dashboard.html` | نسخهٔ تک‌فایلی برای اجرای سریع |
| `scripts/serve.mjs` | سرور محلی بدون وابستگی |
| `scripts/build-standalone.mjs` | تولید نسخهٔ تک‌فایلی |
| `scripts/verify.mjs` | بررسی سینتکس، فایل‌ها و نمودارها |
| `tests/dom-qa.cjs` | آزمون تعامل‌ها با jsdom |
| `tests/standalone-qa.cjs` | آزمون نسخهٔ مستقل |
| `tests/liquid-theme-qa.cjs` | آزمون دو تم، ذخیره‌سازی، فارسی و رفتار منو در اندازه‌های مختلف |
| `VALIDATION.json` | نتایج بررسی و محدودیت‌ها |

برای تغییر اعداد و محصولات، `data.js` را ویرایش کنید. رنگ‌ها و شفافیت‌های هر تم در ابتدای `liquid-glass.css` هستند. قواعد واکنش‌گرایی در `liquid-responsive.css` قرار دارند. منوها و عنوان صفحات در `navItems` و `pageMeta` فایل `app.js` تعریف شده‌اند.

بعد از تغییر فایل‌های اصلی، نسخهٔ تک‌فایلی را دوباره بسازید:

```bash
npm run check
npm run build
```

فایل تک‌فایلی خروجی build است و بازنویسی می‌شود؛ تغییرات اصلی را در فایل‌های جداگانه اعمال کنید.

## آزمون‌ها

برای اجرای آزمون‌ها فقط در محیط توسعه:

```bash
npm install
npm test
npm run test:standalone
npm run test:themes
```

jsdom وابستگی آزمون است و هنگام استفادهٔ داشبورد بارگیری نمی‌شود.

۱۱ گروه آزمون تعامل‌های قبلی و ۱۲ گروه آزمون تم و نسخهٔ مستقل با صفر خطای JavaScript و صفر درخواست شبکه موفق شدند. انتخاب تم، ذخیره و بازیابی، تنظیم اولیهٔ سیستم، حفظ داده‌های قدیمی، پنج صفحه در دو تم، فارسی، تنظیمات و رفتار کشوی موبایل بررسی شدند. نسخهٔ تک‌فایلی جداگانه با آدرس مستقیم فایل اجرا شد و تصاویر و پس‌زمینه‌های داخلی آن بررسی شدند. رفتار تولید PDF نیز در آزمون‌های قبلی برنامه بررسی شده است.

ابزار مرورگر واقعی در محیط ساخت در دسترس نبود. بررسی تعامل‌ها در DOM و بازبینی کد انجام شده است؛ تطبیق پیکسلی، رندر نهایی مرورگر و دستگاه واقعی به عنوان آزمون انجام‌شده ثبت نشده‌اند.

## استفاده در پروژهٔ اصلی

فایل‌های `dist` را می‌توان روی هاست فایل ثابت قرار داد. برای اتصال به محصول واقعی، داده‌ها و عملیات داخل `app.js` را به APIهای احراز هویت‌شده متصل کنید. ساختار SVG نمودارها و بیشتر CSS از منطق داده و عملیات جداست.

مبنای این تحویل HTML، CSS و JavaScript استاندارد است. اجرای آن به React، Next.js، کتابخانهٔ نمودار یا API پولی احتیاج ندارد.
