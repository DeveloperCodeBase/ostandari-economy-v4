# سکوی تصمیم‌یار اقتصادی استاندار تهران
## (Tehran Province Economic Decision & Intelligence Platform v3.0)

> **سامانه حاکمیتی تصمیم‌یار و مرکز پایش ۳۶۰ درجه اقتصادی استانداری تهران**  
> توسعه‌یافته بر اساس نیازمندی‌های معاونت هماهنگی امور اقتصادی استانداری تهران و شرکت شبکه هوشمند ابتکار ویستا (دانش‌بنیان).

---

## 🏛️ معرفی اجمالی پروژه
سکوی تصمیم‌یار اقتصادی استاندار تهران یک سامانه پیشرفته و چندلایه است که داده‌های اقتصادی، مالی، صنعتی، کشاورزی، گمرکی و لجستیکی استان تهران (شامل ۱۶ شهرستان، ۲۲ شهرک صنعتی، ۶ گمرک، شبکه بانکی و زنجیره گندم و نان) را به صورت بلادرنگ گردآوری، تحلیل و در قالب ابزارهای تصمیم‌یار حاکمیتی ارائه می‌دهد.

### 🌟 ویژگی‌های کلیدی سامانه:
1. **پایش ۳۶۰ درجه و نبض کلان پایتخت:**
   - رصد ۲۰.۹۴٪ سهم استان تهران از تولید ناخالص داخلی (GDP) کشور
   - پایش درآمدهای عمومی ۳۹۳ همت (رشد ۷۷ درصدی) و مالیات ارزش افزوده ۷۳ همت
   - پایش ۶۰.۵٪ سپرده‌های بانکی کل کشور در تهران و نسبت مصارف به منابع (LDR)
2. **اتاق جنگ اقتصادی و شبیه‌ساز What-If:**
   - تنظیم ۱۲ اهرم کلان سیاستی (سهمیه آرد، سقف قیمت، تزریق ذخایر، دیماند برق، اعتبارات و...)
   - شبیه‌سازی اثرات متقاطع بر تورم، رضایت عمومی، تولید و تولید پیش‌نویس مصوبه استانداری
3. **شورای اجماع چندعامله (Multi-Agent Consensus Chamber):**
   - استقرار ۱۰ عامل هوشمند تخصصی (از AGT-01 تا AGT-10) با الگوریتم تعادل نش
   - مناظره و حل تعارضات بخشی بین دستگاه‌ها (صمت، جهاد، غله، بانک‌ها و رفاه)
4. **میز کار مقایسه چندجانبه ۱۶ شهرستان:**
   - نقشه ماهواره‌ای تعاملی ۳ بعدی تهران
   - نمودار راداری ۶بعدی مقایسه سرانه‌ها، آسیب‌پذیری‌ها و پتانسیل‌های تولید
5. **تابلوی برخط نرخ ۲۰ کالای اساسی:**
   - مقایسه بلادرنگ نرخ مصوب دولتی، نرخ میادین شهرداری تهران و بازار آزاد
   - محاسبه شکاف قیمتی (Spread) و روزهای پوشش ذخایر انبارهای استراتژیک
6. **کارتابل پیگیری مصوبات ستاد تنظیم بازار و تسهیل تولید:**
   - پیگیری وضعیت مصوبات با پیشرفت فیزیکی، مهلت قانونی و تولید نامه‌های اخطار رسمی
7. **سیستم دوگانه تم (Dual-Theme Liquid Glass):**
   - تم تاریک رسمی حاکمیتی (Sovereign Midnight Dark)
   - تم روشن پرسلان کریستالی با کنتراست ۱۰۰٪ (High-Contrast Porcelain Light)
   - سایدبار هوشمند راست‌چین، بدون تداخل با سربرگ یا محتوا و قابل جمع‌شدن

## 🤖 شبکه ۱۰ عامل هوشمند تخصصی (AI Agents)
- **AGT-01:** استراتژیست کلان اقتصاد تهران (سهم GDP، تورم و تاب‌آوری)
- **AGT-02:** ممیز هوشمند مالیاتی و خزانه‌داری (وصول عوارض، مولدسازی املاک)
- **AGT-03:** بازرس شبکه بانکی و هدایت اعتبار (کنترل LDR و تسهیلات سرمایه در گردش)
- **AGT-04:** دیده‌بان شهرک‌های صنعتی و احیای کارخانجات راکد (۲۲ شهرک صنعتی)
- **AGT-05:** ناظر تنظیم بازار، میادین تره‌بار و سامانه ۱۲۴ (۲۰ قلم کالای اساسی)
- **AGT-06:** نگهبان زنجیره گندم، سیلوها، آرد و نانینو (۹,۶۴۰ نانوایی)
- **AGT-07:** پایشگر کشاورزی نوین، گلخانه‌ها و امنیت زیستی (دشت ورامین، پیشوا و پاکدشت)
- **AGT-08:** فرمانده گمرکات ۶گانه و روان‌سازی ترخیص و لجستیک (مسیر سبز گمرکی)
- **AGT-09:** تحلیلگر بازار کار، اشتغال و رفاه اجتماعی (سامانه رصد)
- **AGT-10:** کنترلگر ناترازی انرژی و ۵ سد آب استان تهران (پایداری دیماند و آب شرب)

## 🛠️ فناوری‌ها و معماری فنی
- **فریم‌ورک:** Next.js 15+ (App Router) با TypeScript 5
- **استایل‌دهی:** Tailwind CSS v4، تم اختصاصی متریال شیشه‌ای سیال (Liquid Glass)
- **هوش مصنوعی:** Google GenAI SDK (`@google/genai`) با مدل `gemini-3.8-flash` و ابزار جستجوی وب (Search Grounding)
- **انیمیشن‌ها:** `motion` (`motion/react`)
- **آیکون‌ها:** `lucide-react`
- **کارتوگرافی و نقشه:** Leaflet و نقشه SVG برداری ۱۶ شهرستان استان تهران

## 🚀 راهنمای نصب و راه‌اندازی

### ۱. پیش‌نیازها
- **Node.js:** نسخه ۲۰ یا بالاتر (توصیه: Node.js 22 LTS)
- **مدیر بسته:** npm

### ۲. کلون کردن و نصب وابستگی‌ها
```bash
git clone https://github.com/DeveloperCodeBase/ostandary-economy-v3.git
cd ostandary-economy-v3
npm install
```

### ۳. تنظیم متغیرهای محیطی
یک فایل `.env.local` در ریشه پروژه ایجاد کنید:
```env
# کلید سرویس هوش مصنوعی Gemini (سمت سرور)
GEMINI_API_KEY=your_gemini_api_key_here
PORT=3000
```
> یک فایل نمونه در `.env.example` نیز برای راهنمایی قرار دارد.

### ۴. اجرای محیط توسعه
```bash
npm run dev
```
سامانه در آدرس `http://localhost:3000` در دسترس خواهد بود.

### ۵. ساخت نسخه نهایی برای استقرار (Production Build)
```bash
npm run build
npm run start
```
